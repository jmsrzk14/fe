# 🚀 Next.js Project

Proyek ini dibangun menggunakan [Next.js](https://nextjs.org/)

---

## 📦 Teknologi Utama
- **Next.js** — React Framework untuk SSR & SSG
- **React** — Library UI berbasis komponen
- **Tailwind CSS** — Styling modern berbasis utility
- **Node.js** — Runtime environment untuk JavaScript

---

## 🛠️ Persyaratan Sistem
Sebelum memulai, pastikan sudah terpasang di sistem Anda:
- **Node.js** v18 atau lebih baru  
- **npm** atau **yarn** sebagai package manager  
- **Git** untuk version control  

---

## ⚙️ Instalasi

1. npm install
2. npm run build
